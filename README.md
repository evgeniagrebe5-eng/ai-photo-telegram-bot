# AI Photo Gallery — clean build 2026-09-15

Новая отдельная сборка. Рабочую ветку stable-working-2026-09-12 не изменяет.

## Включено

- Осенние образы
- Зимние образы
- Авторский промт
- Парные фото
- Женские портреты
- Мужские портреты
- Студийные фото
- Стикеры
- Юмористические фото
- СВОЙ ПРОМТ
- 1 бесплатная генерация для обычного пользователя
- Telegram ID 5431086812 и администратор — без лимита
- Платные пакеты 1 / 3 / 5 / 10 фото
- Админ-подтверждение оплаты
- Сохранение каждого образа в своей галерее
- У каждого образа собственные reference photo + prompt
- Кнопка СДЕЛАТЬ ФОТО из галереи
- Кнопка СДЕЛАТЬ ФОТО в посте канала ведёт сразу к конкретному образу

## Render

Start command:
python bot.py

Required environment variables:
BOT_TOKEN
OPENAI_API_KEY
ADMIN_ID

Optional:
CHANNEL_USERNAME=@galereyapromt
BOT_USERNAME=aiphoto_gallery_bot
OPENAI_MODEL=gpt-image-2
KASPI_DETAILS=...

## Важно

JSON-файлы в data/ находятся на файловой системе сервиса. Для постоянного хранения при перезапусках/redeploy лучше подключить постоянную БД или внешнее хранилище.
